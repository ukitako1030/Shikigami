Use case: ui-mockup. Create one exceptionally polished, realistic Windows desktop application main-screen design concept for an original app named "Shikigami". This is a product design preview, not an existing implemented screen. Landscape 16:10, high resolution, straight-on perfectly flat screenshot; the app window fills the image, no monitor, no desktop wallpaper, no perspective. Target ordinary Japanese Windows users, not developers. Product: the user keeps using their PC while an AI agent operates a separate hidden Google Chrome workspace. Browser work only for the first release.

Art direction: quiet Japanese precision, beautiful restrained contemporary desktop software. Deep ink navy slim sidebar, warm ivory main canvas, muted sea-glass teal accents, excellent spacious typography, thin borders, subtle depth, generous negative space. Refined original folded-paper spirit/bird emblem for Shikigami, small, elegant, no anime figure. Avoid generic SaaS grid of cards, neon gradients, stock photos, overly rounded blobs, excessive metrics. Balance utility and a memorable identity. Use fluent legible Japanese text with accurate glyphs, large enough to read. Fonts resemble contemporary Japanese sans-serif.
